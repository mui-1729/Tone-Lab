# MVP仕様

## ユーザーストーリー

ギタリストとして、参考音と自分の録音をアップロードし、何が違うかと、どちらへ調整すべきかを知りたい。

## 入力

- 参考音源
- 自分の音源
- 対応形式: WAV / MP3 / FLAC / OGG
- 最大サイズ: 1ファイル25MB
- 解析対象: 冒頭から最大30秒

## 出力

### 物理特徴

- RMS音量
- ピーク音量
- クレストファクター
- ダイナミックレンジ
- スペクトル重心
- スペクトル帯域幅
- 85%ロールオフ周波数
- スペクトル平坦度
- ゼロ交差率
- オンセット強度
- 周波数帯ごとのエネルギー比率

### 質感差

比較値は -100〜+100 です。正は「自分の音のほうがその質感を強く持つ」、負は「参考音のほうが強い」を表します。

- Brightness / 明るさ
- Body / 太さ
- Attack / アタック
- Compression / 圧縮感
- Roughness / 粗さ

## 成功条件

最低20組の実音源で、上位3つの差分説明について、評価者の70%以上が「方向性は納得できる」と回答すること。

これは最終的な精度目標ではなく、ルールベースMVPを次の学習段階へ進めるための判定基準です。

## 注意

「明るさ」などの質感語は物理量そのものではありません。初期版では複数の音響特徴を組み合わせた仮説的な指標として扱い、ユーザー評価によって修正します。
