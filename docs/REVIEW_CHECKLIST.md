# Tone Lab 2.0 最終実機レビュー

このチェックリストは、自動テストでは確認できないWindows・Chrome・音声入力・聴感を最終確認するためのものです。

## 0. 環境

```text
確認日:
Windowsバージョン:
Chromeバージョン:
入力機器:
ギター / 使用機材:
```

## 1. 起動

```bash
git switch main
git pull
docker compose up --build
```

- [ ] Webが`http://localhost:3000`で開く
- [ ] 画面に`TONE LAB / 2.0`と表示される
- [ ] API仕様が`http://localhost:8000/docs`で開く
- [ ] ブラウザのコンソールに重大なエラーがない

## 2. 参考音と区間選択

長めの参考音を読み込みます。

- [ ] 音源を再生できる
- [ ] 開始・終了位置を変更できる
- [ ] 5秒・10秒・15秒の区間プリセットが動く
- [ ] 選択区間をループ再生できる
- [ ] 区間を変更すると古い比較結果が安全にクリアされる

## 3. ブラウザ録音

ChromeからマイクまたはUSBオーディオ入力を許可します。

- [ ] 入力機器を選択できる
- [ ] ギター演奏に反応してレベルメーターが動く
- [ ] クリッピング時に警告が出る
- [ ] 録音開始・停止ができる
- [ ] 参考区間の長さに合わせて録音上限が変わる
- [ ] 録音した音を再生できる
- [ ] 録り直しと通常ファイル選択の両方が使える

## 4. 同一音源

同じWAVを参考音・自分の音の両方へ入れます。

- [ ] 位置補正がほぼ0秒
- [ ] 一致度が高い
- [ ] 5軸がすべてほぼ0
- [ ] 周波数グラフが重なる
- [ ] 優先調整プランが「大きな調整不要」になる

## 5. 既知のEQ変更

元音源とTrebleを上げた音源を比較します。

- [ ] 明るさが主な差になる
- [ ] 圧縮感・粗さが極端に動かない
- [ ] 周波数グラフで高域側の差が見える
- [ ] 優先調整プランが高域を戻す方向を示す

## 6. 別録音とA/B

同じフレーズを2回録音し、録音開始を0.5〜1秒程度ずらします。

- [ ] 補正する音源と秒数の方向が妥当
- [ ] A/B切替時に同じフレーズ位置が維持される
- [ ] 音量マッチONで大きさの差に惑わされにくい
- [ ] 音量マッチOFFで実レベルも確認できる
- [ ] 共通シークと再生停止が安定して動く

## 7. 入力警告

- [ ] クリップした音源で警告が表示される
- [ ] 音量差が大きい2音源で比較条件の警告が表示される
- [ ] 極端に小さい音源で警告が表示される
- [ ] 異なるフレーズでは一致度警告が表示される
- [ ] 低一致度時に無理な位置補正を適用しない

## 8. 調整セッション

同じ参考音で3テイク以上比較します。

- [ ] 最初の比較後に端末内ライブラリへ保存される
- [ ] 「この参考音で次のテイク」から再録音できる
- [ ] 各テイクの差と前回比が履歴へ追加される
- [ ] 最新テイクの変更メモを保存できる
- [ ] 直近最大3テイクの中央値が表示される
- [ ] ばらつきと方向一致率が表示される
- [ ] 5軸それぞれに信頼度と理由が表示される
- [ ] セッション名を変更できる
- [ ] Markdown / JSONの履歴を保存できる

## 9. 端末内ライブラリ

- [ ] Chromeを再読み込みしてもセッション一覧が残る
- [ ] 保存済みセッションを開くと参考音・最新テイク・結果が復元される
- [ ] 同じ参考音で次のテイクを追加できる
- [ ] セッションを個別削除できる
- [ ] すべて削除できる
- [ ] 保存容量と永続保存状態が表示される

## 10. ブラインドA/B

2テイク以上あるセッションで実施します。

- [ ] 回答前はX/Yの正体とファイル名が表示されない
- [ ] 参考音・X・Yの位置が揃っている
- [ ] 音量差が過度な判断材料にならない
- [ ] X / Y / 判断できないを選べる
- [ ] 回答後だけ正体が公開される
- [ ] 割り当てを変えて再試行できる
- [ ] 回答履歴がセッションJSONへ含まれる

## 11. リアルタイム比較

通常比較済みのセッションを開いて実施します。

- [ ] リアルタイム比較を開始できる
- [ ] 正しい入力機器を選択できる
- [ ] 演奏に反応して入力レベルが更新される
- [ ] 約1秒単位で5軸が更新される
- [ ] 無音時に不要な解析が連続しない
- [ ] 表示安定度・信頼度・ばらつきを確認できる
- [ ] 停止できる
- [ ] 停止時の最後の区間を通常テイクとして保存できる
- [ ] 保存後に通常結果、履歴、A/Bへ反映される
- [ ] マイク拒否または非対応時に通常比較の案内が表示される

## 12. 聴感評価と集計

- [ ] 5軸ごとに合っている / 違う / わからないを記録できる
- [ ] 全体評価とメモを入力できる
- [ ] 評価JSONを保存できる
- [ ] 複数の評価JSONを集計画面へ読み込める
- [ ] 不正JSONが理由付きでスキップされる
- [ ] 重複評価が二重集計されない
- [ ] 軸別一致率と差の大きさ別集計が表示される
- [ ] 問題候補一覧を確認できる
- [ ] 集計JSONとCSVを保存できる

## 13. レポートと表示

- [ ] 比較Markdownを保存できる
- [ ] 比較JSONを保存できる
- [ ] 印刷プレビューが読みやすい
- [ ] デスクトップ幅で崩れない

- [ ] 重大なデータ消失がない
