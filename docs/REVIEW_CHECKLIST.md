# Tone Lab MVP 1.0 最終レビュー

このチェックリストは、自動テストでは確認できない実機・ブラウザ・聴感を最終確認するためのものです。

## 1. 起動

```bash
git switch main
git pull
docker compose up --build
```

- [ ] Webが`http://localhost:3000`で開く
- [ ] 画面に`TONE LAB / MVP 1.0`と表示される
- [ ] ブラウザのコンソールに重大なエラーがない

## 2. 同一音源

同じWAVを参考音・自分の音の両方へ入れます。

- [ ] 位置補正がほぼ0秒
- [ ] 一致度が高い
- [ ] 5軸がすべてほぼ0
- [ ] 周波数グラフが重なる
- [ ] 優先調整プランが「大きな調整不要」になる

## 3. 既知のEQ変更

元音源とTrebleを上げた音源を比較します。

- [ ] 明るさが主な差になる
- [ ] 圧縮感・粗さが極端に動かない
- [ ] 周波数グラフで高域側の差が見える
- [ ] 優先調整プランが高域を戻す方向を示す

## 4. 別録音

同じフレーズを2回録音し、録音開始を0.5〜1秒程度ずらします。

- [ ] 補正する音源と秒数の方向が妥当
- [ ] A/B切替時に同じフレーズ位置が維持される
- [ ] 音量マッチONで大きさの差に惑わされにくい
- [ ] 音量マッチOFFで実レベルも確認できる

## 5. 入力警告

- [ ] クリップした音源で警告が表示される
- [ ] 音量差が大きい2音源で比較条件の警告が表示される
- [ ] 異なるフレーズでは一致度警告が表示される

## 6. 保存と再比較

- [ ] Markdownレポートを保存できる
- [ ] JSON結果を保存できる
- [ ] 印刷プレビューが読みやすい
- [ ] 5軸の聴感評価JSONを保存できる
- [ ] 「新しく比較」で初期状態へ戻る
- [ ] リセット後に同じファイルを再選択できる

## 7. 表示

- [ ] デスクトップ幅で崩れない
- [ ] ブラウザ幅を狭くしても操作できる
- [ ] 長い日本語ファイル名がカードからはみ出さない
- [ ] キーボードだけでも主要ボタンを操作できる
