# Initial issue draft

## Title

`feat: 実ギター音源で5つの質感差を検証する`

## Body

### 目的

現在のルールベース比較が、実際のギター音でも人間の聴感と同じ方向を示すか確認する。

### 対象

同じDIまたは同じフレーズを使い、設定だけを変えた音源ペアを最低10組作る。

例:

- Trebleを下げた音 / 上げた音
- Low Midを下げた音 / 上げた音
- コンプレッサーOFF / ON
- Gainが低い音 / 高い音
- ピッキングが弱い音 / 強い音

### 実施内容

- [ ] 音源ペアを10組以上用意する
- [ ] Tone Labの解析結果を保存する
- [ ] 解析前に人間が予想した方向を記録する
- [ ] 明るさ・太さ・アタック・圧縮感・粗さごとに一致率を計算する
- [ ] 明らかに誤る条件を記録する
- [ ] 係数調整は検証結果を確認してから別PRで行う

### 完了条件

- 各音源ペアの条件と結果が表になっている
- 5軸それぞれの方向一致率が分かる
- 次に修正すべき指標が1つ以上特定されている

### Non-Goals

- 機械学習モデルの導入
- HX Stomp設定の自動生成
- SNS動画やバンドミックスの解析
